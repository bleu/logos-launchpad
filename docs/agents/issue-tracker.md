# Issue tracker

Use Linear team `logos` and project `logos-launchpads`. Issues use `LOG-<number>`. Look up identifiers with the connected tools instead of recording them in repo docs.

Before work, read the issue, comments, linked docs, dependencies and acceptance criteria. Report conflicting decisions and pending approvals.

Do not create duplicate GitHub or local issues. If Linear is unavailable, report the blocker. Get approval before changing remote records unless the user has requested the change.
